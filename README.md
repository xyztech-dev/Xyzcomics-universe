# XYZ Comics Universe | Independent Publishing Studio Hub

A professional, single-file interactive web application built for **XYZ Comics**—an independent graphic novel publishing home showcasing distinct, mature superhero and sci-fi universes.

---

## ⚡ Key Features & Architecture

* **Modern Dark Slate Aesthetic:** Styled using Tailwind CSS with a deep dark slate background (`#0b0d11`), frosted glass navigation (`backdrop-filter: blur`), and sharp amber/gold accents (`#e5a93b`).
* **Dynamic Character Art Studio & Uploader:** Every superhero card on the platform includes an interactive **"Upload Art"** overlay button. You can instantly drop your generated character artwork or reference images right into any character portrait on the fly.
* **Strictly Siloed Interactive Script Reader:** Clicking "Read Script" or "Read Preview" opens a modal displaying authentic, project-specific comic panel descriptions, captions, and shot labels tailored precisely to the selected universe without mixing canon.
* **Digital Store & Pre-Orders:** Simulated digital and print issue purchasing catalog with interactive toast notification confirmations.
* **Creator Pitch Studio:** A dedicated submission portal for independent writers and pencilers to submit portfolio links and story pitches to the XYZ Comics editorial team.
